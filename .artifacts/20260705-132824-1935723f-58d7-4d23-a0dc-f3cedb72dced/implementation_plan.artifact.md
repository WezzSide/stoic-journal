# Implementation Plan - Phase 8: Habit Reinforcement & UX Polish

This phase focuses on increasing user retention and adding delightful UI details to the AI Reflection feature.

## Proposed Changes

### 1. UI Polish: AI Typewriter Effect
- **Objective**: Improve the visual flow of AI reflections to match the "philosopher contemplating" persona.
- **Action**: Implement a custom `TypewriterText` composable in `:core:common` and apply it to `AiReflectionScreen`.

### 2. Home Screen Widget: Stoic Quote of the Day
- **Objective**: Bring Stoic wisdom directly to the user's home screen.
- **Technical**: Use `Glance` (Jetpack's Compose-based widget library).
- **Files**:
    - [NEW] `core:notifications`: `QuoteWidget.kt`, `QuoteWidgetReceiver.kt`.
    - `AndroidManifest.xml`: Register the widget receiver.

### 3. Streak Insights & Retention
- **Objective**: Provide more than just a number. Show users *why* their streak matters.
- **Action**:
    - [NEW] `GetStreakInsightsUseCase`: Analyzes entry consistency and returns encouraging Stoic feedback (e.g., "Consistency is the soul of character").
    - Update `TodayViewModel` to display these insights.

### 4. Advanced Summary (Personalization)
- **Objective**: Weekly reflection summaries generated by AI.
- **Technical**: Create a background worker that triggers every Sunday to summarize the week's themes.

## Verification Plan

### Automated Tests
- `./gradlew test` (Verify `GetStreakInsightsUseCase` logic).
- Unit tests for the new `Typewriter` state machine.

### Manual Verification
- Add the widget to the emulator home screen.
- Trigger the AI reflection and observe the typewriter animation.
- Verify streak insights appear on the Today screen after multiple entries.
